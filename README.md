# Albion Market Helper 🛡️💰

Este é um projeto pessoal desenvolvido como hobby, com o objetivo principal de aprender a utilizar **Inteligência Artificial** na prática, aplicando-a em um cenário real de desenvolvimento de software. O projeto está sendo construído em minhas horas vagas e serve como um laboratório de experimentação técnica.

## 📝 Sobre o Projeto

O **Albion Market Helper** é uma ferramenta web projetada para auxiliar jogadores do MMORPG **Albion Online** a analisarem dados de mercado e identificarem oportunidades de lucro. A aplicação consome dados do [Albion Online Data Project (AODP)](https://www.albion-online-data.com/) e oferece uma interface amigável para busca e comparação de preços entre diferentes cidades e o Mercado Negro (Caerleon).

## 🚀 Objetivos de Aprendizado

- **Integração com IA:** Utilizar agentes de IA (como este que escreve este README) para auxiliar no planejamento, codificação, depuração e documentação do projeto.
- **Desenvolvimento Moderno:** Praticar o uso de tecnologias de ponta como Next.js 15, TypeScript e Tailwind CSS.
- **Arquitetura de Dados:** Lidar com APIs externas, processamento de grandes arquivos JSON e implementação de proxies para contornar limitações de CORS.

## ✨ Funcionalidades (Em desenvolvimento)

- [x] **Base de Dados de Itens:** Processamento e filtragem de metadados do jogo (Item IDs e nomes traduzidos).
- [ ] **Busca Inteligente:** Campo de pesquisa com sugestões dinâmicas para localizar itens rapidamente.
- [ ] **Filtros Avançados:** Seleção por Tier, Encantamento e Qualidade.
- [ ] **Comparador de Preços:** Visualização de preços em tempo real em todas as cidades principais.
- [ ] **Destaque de Lucro:** Cálculo automático para identificar onde comprar mais barato e onde vender mais caro.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** [Next.js](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Fonte de Dados:** API do Albion Online Data Project

## 📂 Estrutura do Repositório

- `albion-market-app/`: O código-fonte da aplicação web.
- `Projeto Albion/`: Documentação, requisitos e roteiro de desenvolvimento.
- `scripts/`: Scripts auxiliares (ex: download e filtragem de dados de itens).

## ⚙️ Como Executar (Desenvolvimento)

1. Entre na pasta da aplicação:
   ```bash
   cd albion-market-app
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:3000` no seu navegador.
